# Project Final Review and Reflection

## Addressing Relevant Implications

### Functionality

To ensure I addressed functionality I tested features constantly 
throughout production and got my end-user to test my project at multiple points
during production. I also ran my project through a validator to make sure my code follows 
convention


### Usability

To ensure usability I tested regularly and got my end user to test as well. I also made to sure to follow
convention and apply Nielson's heuristics when ever possible and necessary. Examples of this are always having the 
option to back out of a design before it is submitted and showing flash messages that keep the user informed as to 
what is happening in the system


### Accessability

To make sure my website is accessible I used semantic tags where it made sense and added alt text to any images. 
I also checked the readability of my text regularly to ensure it was easy to read particularly for the visually impaired



### Privacy

The website respects privacy by asking for very minimal information from the user and ensuring that passwords are hashed and saved
securely to stop any account breaches


### End-user

I met end-user requirements by:
- Writing content in a way that is accessible to all age groups and levels of education by keeping designs simple and easy to digest
- Prioritising the main tasks users want to complete quickly by minimizing steps wherever possible
- Making the interface as easy to use as possible for someone who is not very tech literate by using large obviously 
  labelled buttons etc

I also got feedback from my end-user regularly
